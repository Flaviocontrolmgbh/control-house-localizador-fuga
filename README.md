# Control House – Localizador de Fuga

Aplicativo Android offline para auxiliar o diagnóstico de fuga para terra por comparação de medições de resistência de isolamento antes e depois do seccionamento de trechos.

## APK
O GitHub Actions compila automaticamente um APK de teste a cada atualização da branch `main`. Abra a aba **Actions**, selecione **Gerar APK Android**, abra a execução mais recente e baixe o artefato **ControlHouse-Localizador-de-Fuga-APK**.

## Segurança
Realize ensaios de isolamento somente com o circuito desenergizado e seguindo os procedimentos do instrumento, NR-10 e normas aplicáveis. O resultado do aplicativo é auxílio diagnóstico e deve ser confirmado em campo.
